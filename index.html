About this project

This website presents 15 CSS practice solutions, organized into Beginner, Intermediate, and Challenging levels.

It demonstrates semantic HTML5, external CSS, Flexbox, Grid, responsive design, accessibility, and dark mode.

Beginner — 5 exercises

Exercise 1 — Text Styling

Colors, typography, weight, and spacing.

Exercise 2 — Box Model

Content, padding, border, and margin.

Exercise 3 — Selectors

Structural and pseudo-class selectors.

Exercise 4 — Links

Interactive link and button styling.

Exercise 5 — Card

A reusable card component.

Intermediate — 5 exercises

Exercise 6 — Flexbox Navigation

Flexible navigation layout.

Exercise 7 — Flexible Cards

Responsive cards with Flexbox.

Exercise 8 — CSS Grid

Multi-column Grid layout.

Exercise 9 — Responsive Units

Clamp, percentages, and flexible sizing.

Exercise 10 — Two Columns

Responsive main content and sidebar.

Challenging — 5 exercises

Exercise 11 — Positioning

Relative and absolute positioning.

Exercise 12 — Pseudo-elements

Decorative generated content.

Exercise 13 — Accessible Form

Labels, focus states, and controls.

Exercise 14 — CSS Variables

Reusable custom properties.

Exercise 15 — Dashboard

Combined responsive layout.

Accessibility

This project includes a skip link, visible keyboard focus, semantic landmarks, ordered headings, responsive navigation, readable contrast, and no color-only instructions.
